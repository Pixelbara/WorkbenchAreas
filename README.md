# Workbench Areas (RimWorld 1.6 Mod)

A RimWorld mod that allows restricting ingredient search for any workbench or crematorium bill to specific allowed areas (including the Home area and custom player zones).

The area selector is seamlessly placed directly inside the bill configuration window, right beneath the search radius slider.

## Features
- **Area Restrictions**: Limit ingredient search for bills to any specific area/zone.
- **Crematorium Support**: Full support — yes, no more suffering when setting up corpse disposal!
- **Safe Mid-Game**: Safe to add or remove mid-game on existing savegames.
- **Vanilla Integration**: Clean, vanilla-friendly UI placement.
- **High Compatibility**: Theoretically compatible with all mods that add or modify workbenches.

> *Note: This mod was created with AI assistance.*

## 简体中文 (Simplified Chinese)

允许你将任何工作台或焚化炉清单（Bill）的原料搜索限制在指定的允许区域内（包括居住区和自定义玩家区域）。

- **原生 UI**：无缝融入原版 UI 界面。
- **高度兼容**：理论上兼容所有修改或添加工作台的 Mod。

> *注：本 Mod 包含 AI 辅助制作的内容。*

## Installation
1. Download the latest release from the [Releases](../../releases) tab.
2. Unpack into your RimWorld `Mods/` directory.
3. Enable Harmony and **Workbench Areas** in the in-game mod menu.
