# Workbench Areas (RimWorld 1.6 Mod)

A RimWorld mod that allows restricting ingredient search for any workbench or crematorium bill to specific allowed areas (including Home Area and custom player-created areas).

## Features
- Adds a target area selection button inside the bill configuration window (directly under the search radius slider).
- Overrides ingredient validation, ignoring items outside the designated area regardless of search radius.

## Installation
1. Download the latest release from the [Releases](../../releases) tab.
2. Unpack into your RimWorld `Mods/` directory.
3. Enable Harmony and **Workbench Areas** in the in-game mod menu.
